# 验证码可选开关设计

## 文档状态

- 日期：2026-08-11
- 状态：用户已确认书面设计
- 范围：注册和匿名试用的人机验证

## 目标

验证码在内部测试、邀请测试和正式公开阶段都默认关闭。关闭时，用户不看到验证码控件，浏览器不加载阿里云验证码资源，服务端不要求验证码参数，也不调用阿里云验证码 API。

保留现有阿里云验证码集成，以便用户以后主动决定启用时只需补充配置并重新部署，不需要重新开发。

## 配置与启动

新增布尔配置 `CAPTCHA_ENABLED`，默认值为 `false`。

- `CAPTCHA_ENABLED=false`：生产配置不要求 `CAPTCHA_SCENE_ID` 或 `CAPTCHA_PREFIX`。
- `CAPTCHA_ENABLED=true`：生产配置必须同时提供安全有效的场景 ID 和前缀，否则启动失败。
- 验证码开关不与 `ROLLOUT_STAGE` 绑定，公开阶段也允许保持关闭。
- 本地和自动测试环境始终使用本地验证器，不因该开关访问阿里云。

## 服务端行为

认证依赖根据开关选择验证器：

- 开启时使用现有 `AliyunCaptchaVerifier`。
- 关闭时使用明确命名的禁用验证器，不发起外部请求并直接放行验证码检查。

注册和匿名试用请求的 `captcha_token` 改为可选。验证码开启时，缺失或无效令牌仍返回现有的稳定错误；关闭时，无令牌请求可以继续执行。隐私确认、邮箱验证、同源检查、CSRF、账号容量和现有接口限流不变。

## 浏览器行为与 CSP

`/api/auth/captcha-config` 只在生产环境且 `CAPTCHA_ENABLED=true` 时返回启用状态。其他情况不返回场景信息。

关闭时：

- 注册弹窗和首次试用隐私弹窗不显示任何验证码区域或验证码说明。
- 前端不加载阿里云验证码脚本，也不提交占位验证码令牌。
- 内容安全策略不允许阿里云验证码脚本、连接或 iframe 域名。

开启时保留现有弹窗式阿里云验证码流程和精确域名 CSP。

## 保留的防滥用措施

关闭验证码不会放宽以下限制：

- 匿名试用身份使用签名私有 Cookie。
- IP 只保存 HMAC 摘要，不保存原始 IP。
- 同一 IP 在 30 天内最多创建 3 个试用身份。
- 每个试用身份累计最多调用 5 次。
- 全站匿名试用每日最多调用 50 次。
- 注册用户每日最多 10 次、每月最多 50 次。
- 注册、登录、验证邮件和密码重置继续使用各自的接口限流。
- 注册仍要求邮箱验证和隐私政策确认。

## 错误处理

验证码关闭时不会产生验证码加载或服务失败错误。验证码开启时继续保持失败即关闭该次注册或首次试用，不在阿里云验证失败时自动绕过。

配置矛盾必须在应用启动前失败，例如开启验证码却缺少场景配置。错误信息只列出配置字段名，不输出密钥或令牌。

## 测试

增加或调整测试以覆盖：

- 生产环境默认关闭验证码且无需场景配置即可通过配置校验。
- 开启验证码后缺少场景 ID 或前缀会被拒绝。
- 关闭时后端不实例化或调用阿里云验证码客户端。
- 关闭时注册和首次试用可以不提交验证码令牌。
- 关闭时配置接口返回 `enabled=false`，CSP 不含阿里云域名。
- 开启时原有配置接口、CSP、验证成功和验证失败行为保持不变。
- 前端关闭时隐藏验证码区域且不加载外部脚本。
- 配额、IP 身份限制、邮箱验证、隐私确认和接口限流回归测试继续通过。

## 非目标

- 本次不购买或开通阿里云验证码服务。
- 本次不删除现有阿里云验证码 SDK 和集成代码。
- 本次不改变试用次数、注册用户次数、账号上限或 DeepSeek 调用策略。
- 本次不调用真实 DeepSeek、DirectMail、OSS 或阿里云验证码接口。

# 历史消息附件摘要布局修复设计

## 背景

案件消息中的附件摘要包含三个直接子元素：回形针图标、文件信息和展开箭头。现有网格只声明两列，导致文件信息落入 18px 固定列，长文件名在桌面和移动视口中逐字换行。

## 方案

保持现有 DOM、视觉样式和展开交互不变，仅将 `.message-attachment summary` 的网格调整为三列：

1. 18px 回形针图标；
2. `minmax(0, 1fr)` 文件名及元信息；
3. 18px 展开箭头。

不隐藏图标，不截断文件名，也不重构 JavaScript 附件节点。

## 验收

- 在 1366、936、390、360px 四种视口下，附件摘要及文件信息区域均有有效宽度。
- 文件名保持正常横向排版，并允许在可用内容宽度内换行。
- 展开箭头保持在摘要右侧，展开和收起行为不变。
- 浏览器验收脚本增加附件摘要宽度与溢出断言。
- 全量自动化测试继续通过。
